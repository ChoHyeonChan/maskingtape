# 테이프 로딩 미리보기

`index.html`을 브라우저로 열면 됩니다. 빌드나 서버가 필요하지 않습니다.

- 40% 보기 / 70% 보기: 고정 진행률을 확인합니다.
- 다시 재생: 12초 주기로 테이프가 수평으로 펼쳐집니다.
- `index.html?progress=70`처럼 URL로 진행률을 지정할 수 있습니다.
- 모션 감소 설정에서는 자동 재생 대신 40% 상태를 표시합니다.

브랜드 색상 `#183a8b`, `#102a68`을 사용하며 테이프 아래에 진행률을 표시합니다.
진행률은 디자인 검토용 시뮬레이션이며 실제 API 처리율이 아닙니다.
실제 서비스 로딩과는 연결되지 않은 독립 미리보기입니다.
외부 라이브러리와 이미지 없이 SVG로 제작했습니다.
